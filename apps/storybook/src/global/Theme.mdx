# Theme

프로젝트는 색 하나하나가 아니라 브랜드 스케일·중립 스케일·radius·scaling·글꼴을 고르고 `ThemeProvider`에 주입해요. 컴포넌트는 그 스케일의 단계를 역할에 맞게 사용하므로 브랜드가 바뀌어도 위계가 같게 유지돼요. 이 페이지의 표는 패키지가 실제로 export하는 값을 읽어서 보여줘요.

## 색 스케일

색 하나는 12단계로 펼쳐져요. 1·2는 배경, 3·4·5는 컴포넌트 배경(기본·hover·pressed), 6·7·8은 경계, 9·10은 채운 배경, 11·12는 글자예요. 같은 번호는 라이트와 다크에서 같은 역할이라 컴포넌트 CSS는 번호만 봐요. `brand`·`neutral` 외에 `danger`(red)·`success`(green)·`warning`(amber)·`info`(blue) 스케일을 항상 함께 제공해요.

## 역할 변수

컴포넌트는 스케일을 바로 쓰기도 하고 아래 역할 변수를 거치기도 해요. 채운 배경의 글자는 4.5:1을 만족하도록 9·10·11 중 첫 단계를 자동으로 골라요. 예를 들어 `blue`는 9단계와 흰 글자가 3.3:1이라 11단계를 쓰고, `indigo`는 9단계를 그대로 써요.

## 프로젝트에 주입하기

```tsx
import "@heogeon0/aui/styles.css";
import { ThemeProvider, defaultTheme, defineTheme } from "@heogeon0/aui";
import { Link } from "react-router";

const projectTheme = defineTheme({
  name: "my-service",
  brand: "teal",
  neutral: "sage",
  radius: "large",
  scaling: "100%",
  fontFamily: defaultTheme.fontFamily,
  typography: { body: { size: "1rem", lineHeight: "1.5rem" } },
});

export function Root() {
  return (
    <ThemeProvider theme={projectTheme} mode="system" linkComponent={Link}>
      <App />
    </ThemeProvider>
  );
}
```

`defineTheme()`은 스케일 이름·radius·scaling을 검사하고 객체를 고정해요. `mode`는 `light`가 기본이고 `dark`나 기기 설정을 따르는 `system`을 선택해요. `linkComponent`를 넘기면 `ButtonLink`·`LinkRow`·`Sidebar`·`Breadcrumb`가 그 Link로 렌더링돼요.

브랜드 색이 Radix 스케일에 없으면 `{ light: [...12], dark: [...12] }` 배열을 직접 넘겨요. 투명도 단계(`lightAlpha`·`darkAlpha`)를 생략하면 같은 색을 써요.

## 적용되는 범위

Provider는 theme 하나당 `<style>` 하나를 만들고 `[data-ds-theme][data-ds-mode]` 선택자에 CSS 변수를 선언해요. 중첩한 Provider와 Portal은 가까운 theme을 사용해요. document 전체의 class나 색은 바꾸지 않아요.

## radius와 scaling

`radius`는 배율이에요. 배지는 1단계, 메뉴 항목·작은 버튼은 2단계, 버튼·입력은 3단계, 카드는 4단계, 모달은 5단계를 쓰고 모두 배율에 비례해요. `full`은 버튼·배지·입력이 pill이 되고 카드·모달은 `large`와 같아요. 원형 아바타·thumb와 화면 가장자리에 붙는 Drawer는 형태상 예외예요.

`scaling`은 글자 크기·간격·컨트롤 높이·아이콘 크기를 함께 바꿔요. 입력 글자는 자동 확대를 막기 위해 어느 값에서도 16px 이상이에요.

## 역할별 색 배치

주요 실행에는 primary, 보조 실행에는 secondary(neutral-a3)를 사용해요. ToggleGroup·Select·Sidebar의 지속되는 선택은 brand-a3 배경과 brand-12 글자예요. Tabs는 primary 밑줄이에요. Checkbox·RadioGroup·Switch의 켜짐과 진행량은 primary, 오류·삭제는 danger 스케일이에요. hover·키보드로 탐색 중인 항목은 accent(neutral-a4)로 구분해요.
